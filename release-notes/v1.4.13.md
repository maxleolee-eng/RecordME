# RecordME 1.4.13（35）

macOS 14.0+ · Apple Silicon / Intel 通用版。

## 功能与本版变化

屏幕和摄像头组合录制，支持画中画、左右/上下分屏；可选择麦克风和系统声音，手动暂停继续，可选无人自动暂停，时间/地点水印，日历浏览与中断恢复。录制及暂停期间可打开日历与设置，应用通过 ScreenCaptureKit 排除自身窗口。完整功能见 [产品说明](../README.md)。

这是现有 1.4.13 构建 35 的 GitHub 首次分发，未改变原始 App、DMG 或 ZIP。发布页面与附件新增许可、隐私说明、依赖说明和 Bug 入口。
